# ヤフコメ ユーザー評価表示 (Yahoo! News Rating Visualizer)

## ⚠️⚠️⚠️警告 このスクリプトはプロフィールページに短い間隔でたくさんアクセスします。アクセス制限がかかる可能性があります！⚠️⚠️⚠️

Yahoo!ニュースのコメント欄に、各ユーザーの過去の評価実績（共感した・なるほど・うーん）を視覚化して表示するユーザースクリプトです。
このスクリプトが表示する評価が高くても、そのユーザーが正しいことを言っているという保証はできません。
(この評価はどちらかといえばヤフコメの人たちの評価を示すものなので、評価が高い≒ヤフコメの人たちの考えに合う のような考え方になります)

---

## 🚀 主な機能

### 📊 プロフィールにアクセスすることなく評価データの表示
- **リアクション数の表示**: アカウント全体での「👍 共感した」「💡 なるほど」「👎 うーん」の累計数をバッジで表示。
- **評価比率 (%)**: ポジティブな評価の割合をパーセンテージで算出し、信頼度を確認。
- **評価比率バー**: 評価比率に応じた色（緑〜赤）のバーを表示。
- **エキスパート**: エキスパートには、「💡参考になった」件数と「📰記事数」を表示。
- **プロフィールページ対応**: ユーザーのプロフィールページにも、評価比率(%)と比率バーを表示。


### 🎨 デザイン・視覚効果
- **背景色**: 評価比に応じてコメントの背景を色付け。ポジティブな意見か、批判的な意見かが一目でわかります。
- **背景色の適用条件**: 総評価数（共感 + うーん）が0件のコメントには色付けを行わず、未評価コメントの視認性を維持します。
- **判定基準の切り替え**: 背景色の決定を「アカウント全体」にするか「そのコメントへの評価」にするか選択可能。

### 🛡️ 健全な閲覧をサポート
- **コメントの自動非表示**: 評価比率に基づき、評価が設定された値以下のコメントを自動的に隠します（アカウント全体/個別コメント のいずれを使って計算するか選択可能）。

## ⚙️ 設定ガイド

ユーザースクリプトを使う拡張機能のメニューから **「⚙️ 評価表示設定を開く」** をクリックすると、詳細なカスタマイズが可能です。
Tampermonkeyでのみ動作を確認しています。(多分動くとは思います)

### 主な設定項目
- **一般表示**: 各指標の表示/非表示、指標の丸め設定、バーの表示サイズなど。
- **背景色設定**: 背景色機能のON/OFFおよび判定基準（アカウント全体の評価か、個別コメントの評価か）の選択。
- **非表示設定**: 自動非表示のしきい値や、判定基準（アカウント/コメント/両方）の選択。
- **パフォーマンス**:
    - **データ取得間隔**: サーバーへのリクエスト頻度。短すぎると制限の原因となります。
    - **キャッシュを有効化**: 一度取得したユーザーデータを保存し、再訪問時に即座に表示します。
    - **アクセス制限対策 / ターボモード**: 常時待機時間を設けるか、あるいは「自己責任」で即座に取得する（ターボモード）かを選択します。
